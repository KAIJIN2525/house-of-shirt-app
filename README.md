# House of Shirts - E-Commerce Platform

A full-stack e-commerce mobile application for clothing retail, built with React Native and planned Node.js backend.

## 📁 Repository Structure

```
house-of-shirt-app/
├── client/          # React Native mobile app (Expo)
└── server/          # Node.js backend API (planned)
```

## 📱 Client (Mobile App)

React Native mobile application built with Expo Router, featuring:

- **Onboarding Flow**: Welcome screen and intro slides
- **Authentication**: Login and signup screens
- **Product Discovery**: Home tab with hero carousel, featured categories, and trending products
- **Shop**: Full product catalog with search, filters, and grid/list view toggle
- **Favorites/Wishlist**: Save products with AsyncStorage persistence
- **Shopping Bag**: Cart management
- **User Profile**: Account settings and shipping address management
- **Product Details**: Image carousel with animated pagination dots

### Tech Stack
- React Native + Expo Router
- TypeScript
- NativeWind (Tailwind CSS)
- AsyncStorage
- Context API for state management

### Getting Started

```bash
cd client
npm install
npx expo start
```

See [client/README.md](./client/README.md) for detailed setup instructions.
